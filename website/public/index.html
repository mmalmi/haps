Your starting point: Sirius Business Ltd +

Haps starts with its maintainer as a local trust connection and the Iris package catalog. You can inspect, replace, or disable this starting point. It does not publish a follow event or require your personal secret key.

haps starting-point

Use haps starting-point PUBLIC_KEY to change it, or haps starting-point --clear to remove it. After installing, use haps run iris-drive to open the app. These first GUI packages are for Apple silicon Macs; the Haps CLI also runs on Linux and Windows.

BINARIES OR SOURCE

Choose how
you install.

Use a published binary, or inspect a build recipe from a pinned Git commit. Hashtree Git URLs work through git-remote-htree.

Source build guide ↗
INSPECT FIRST
haps build htree://alice/project \
  --rev FULL_COMMIT_HASH
BUILD WHEN READY
haps build htree://alice/project \
  --rev FULL_COMMIT_HASH \
  --execute --install

Build recipes run with your user permissions. Haps records the source commit; it does not sandbox builds.
